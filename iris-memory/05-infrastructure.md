## Architecture — Sovereign Personal Vault

- Each memory entry: encrypted locally → SHA-256 commitment → chained to previous → Ed25519 signed → Merkle leaf → signed root → exportable receipt
- Selective disclosure: one entry can be proven without exposing the full private timeline
- Components: `memoryEntries`, `memoryRoots`, `memoryReceipts`, `hubSyncQueue`, `hubAudit`

## Cryptographic specification v0.3.0

- AES-256-GCM local encryption
- PBKDF2-SHA-256 (210,000 iterations)
- Ed25519 signatures
- SHA-256 commitments
- Merkle-rooted tamper-evident ledger
- 8 vulnerabilities fixed in v0.3.0
