# Burgess Ambassadors Programme — Building the Community

**Status:** 🚀 LAUNCHING Q2 2026

**Goal:** Create a tiered recognition programme for contributors, early adopters, and case-study winners who advance individual human review in AI governance

---

## Overview

The Burgess Ambassadors programme recognizes and empowers individuals and organisations advancing meaningful human oversight in automated systems.

**Three membership tiers**

| Tier | Recognition Level | Annual Commitment | Benefits | Members |
|---|---|---|---|---|
| **Founder** | Highest; institutional co-founders | Strategic partnership | Co-branding, governance board, quarterly strategy | The Burgess Principle Limited, Wave Utilities, FastLogic, OpenClaw (3-5) |
| **Advocate** | High-impact; case-study winners | Public commitment to Burgess governance | Badge, speaking opportunities, media coverage, annual summit | 10–20 |
| **Contributor** | Active builders; integration submitters | Merge ≥ 1 PR or integration | GitHub badge, profile feature, community credit | 50+ |

## Application Process

### For Founder Partners

**Timeline:** 2 weeks review, quarterly board approval

1. Email: ambassadors@burgess-principle.limited
2. Include:
   - Organisation background
   - SOVEREIGN audit report (independent verifier)
   - Resolved NULL case summary
   - Board-level commitment letter
   - Media readiness (press release + exec availability)

3. Burgess Principle team reviews
4. Q&A call with leadership
5. Final approval + onboarding

### For Advocates

**Timeline:** 1 week review, rolling approval

1. GitHub issue or email: ambassadors@burgess-principle.limited
2. Include (Path A — Case Winner):
   - Case study (published or draft)
   - Regulator/ombudsman letter (if available)
   - Impact metrics (e.g., "Resolved dispute affecting 50k customers")
   - Media requirements (can you go public?)

   OR (Path B — Certified Adopter):
   - Governance documentation
   - Independent audit attachment
   - Commitment to annual compliance
   - Contact for correspondence

3. Verification team reviews (1 week)
4. Approval + badge creation
5. Onboarding call (15 min)

### For Contributors

**Timeline:** Automatic (upon PR merge or case publication)

1. PR merged to burgess-principle or approved framework → Badge awarded automatically
2. GitHub Copilot notification: "Congratulations, you are now a Burgess Contributor"
3. Can claim profile in Community Contributors directory
4. Invited to private Discord/Slack

## FAQ: Becoming an Ambassador

### Q: How long does approval take?

**A:**
- **Contributor:** Automatic (upon PR merge)
- **Advocate:** 1–2 weeks review
- **Founder:** 2–4 weeks (quarterly board review)

### Q: Can we apply for a higher tier?

**A:** Yes. Tier 3 → Tier 2 is automatic (resolve a case or audit to 85% + fee). Tier 2 → Tier 1 requires board approval (must demonstrate 95% + governance leadership).

### Q: Do we have to go public?

**A:**
- **Contributor:** No; GitHub profile can be private
- **Advocate:** Recommended but optional (case study can be anonymised)
- **Founder:** Expected; this is the point of partnership

### Q: What if we lose certification?

**A:**
- Falls below SOVEREIGN threshold? 90-day remediation period. Help offered.
- Still not resolved? Status downgraded (badge removed); re-application process.
- Founder Partner status: Can apply to rejoin as Advocate.

### Q: Can we use this for marketing?

**A:** Yes, with guidelines. Ambassadors can reference Burgess certification in marketing, hiring, investor pitches. But must link to burgess-principle.limited and credit properly.

### Q: How do we leave the programme?

**A:** Email ambassadors@burgess-principle.limited. Badge will be removed from public directory. No penalties; contributions archived for historical record.
